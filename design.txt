# Student Result Manager App

## Project Purpose

The **Student Result Manager App** is a simple Python-based application that allows a teacher to manage student records and check their results.

The application uses **dictionaries, loops, conditional statements, functions, and file handling** to perform student management operations.

---

## Teacher Can

* Add students
* View a particular student
* View all students
* Check a student's result
* Update a student's name
* Update a student's marks
* Delete a student
* Save student data to a file
* Load student data when the program starts
* Exit the application

---

## CRUD Operations

The application demonstrates **CRUD operations**:

### C — Create

The teacher can add a new student.

```python
student[name] = marks
```

### R — Read

The teacher can view one student or all students.

```python
student[name]
```

```python
for name, marks in student.items():
    print(name, marks)
```

### U — Update

The teacher can update:

* Student name
* Student marks

```python
student[name] = new_marks
```

### D — Delete

The teacher can delete a student.

```python
del student[name]
```

# Why Dictionary?

We use a **dictionary to store student data**.

A dictionary stores data in **key-value pairs**.

```python
student = {
    "Insyya": 89,
    "Ali": 75,
    "Sara": 92
}
```

Here:

* `"Insyya"` → key/student name
* `89` → value/student marks

This makes it easy to find a student's marks using their name.

```python
student["Insyya"]
```

Output:

```text
89
```

---

# Why Loop?

We use a **`while` loop to keep the application running**.

```python
while True:
```

The menu keeps appearing until the teacher chooses **Exit**.

```text
Menu
 ↓
Teacher chooses an option
 ↓
Perform operation
 ↓
Show menu again
 ↓
Teacher chooses another option
 ↓
...
 ↓
Exit
```

We also use a **`for` loop** to display all students.

```python
for name, marks in student.items():
    print(f"{name}: {marks}")
```

---

# Why Conditional Statements?

We use **`if`, `elif`, and `else` to write the logic of the application**.

For example:

```python
if name in student:
    print(student[name])
else:
    print("Student not found!")
```

Conditional statements allow the program to make decisions.

For checking results:

```python
if marks >= 40:
    print("You have passed the exam!")
else:
    print("You have failed the exam!")
```

So:

**Condition → Decision → Action**

---

# Why File Handling?

We use **file handling to save student data permanently**.

Without file handling:

```text
Program closes
      ↓
Student data is lost
```

With file handling:

```text
Program
   ↓
Student data
   ↓
students.json
   ↓
Program closes
   ↓
Program starts again
   ↓
Data loaded from students.json
```

We use:

```python
json.load()
```

to load data from the JSON file.

And:

```python
json.dump()
```

to save Python data into the JSON file.
